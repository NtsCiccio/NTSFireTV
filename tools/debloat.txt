# Debloat for Fire TV Stick 4K (2018, AFTMM, Fire OS 6.7.1.1) for NTSFireTV.
# Used by the Gradle tasks `debloat` and `restoreBloat` (see tools/README.md).
#
# Format: one line per package, "# ..." after the name is a comment.
#   [group]            starts a group (applied with -Pgruppo=name)
#   [opz-group]        optional group: NOT included in `debloat` without -Pgruppo, must be requested by name
#   com.example        active: will be disabled
#   #com.example       off: NOT touched (remove the # to include it)
#
# Packages are only DISABLED for the user (pm disable-user --user 0), never uninstalled:
# `./gradlew restoreBloat` re-enables them all.
#
# Based on: the CleanYourTV project's list for this stick (github.com/Gathin23/cleanyourtv),
# revised for NTSFireTV.
#
# NEVER DISABLE (left out of this list on purpose):
#   com.amazon.tv.launcher        Amazon home (protected; NTSFireTV relies on it)
#   com.amazon.tv.settings.*      settings
#   com.amazon.venezia, com.amazon.tigris   Appstore (needed to update apps)
#   com.amazon.tv.ime             keyboard
#   remote and Bluetooth, com.amazon.vizzini (voice search)
#   com.amazon.cast.sink, whisperplay, whisperlink   screen mirroring
#   com.amazon.ftv.screensaver    Amazon screensaver (needed for `restoreScreensaver`)
#   com.amazon.tv.oobe            initial setup (needed after a reset)
#   com.amazon.spotify.mediabrowserservice   Spotify integration
#   com.amazon.firebat            Prime Video
#
# PROTECTED (Fire OS refuses to disable them, no point trying):
#   com.amazon.client.metrics, com.amazon.device.metrics, com.amazon.device.logmanager,
#   com.amazon.device.crashmanager, com.amazon.diode, com.amazon.ftvads.deeplinking,
#   com.amazon.tcomm, com.amazon.tv.csapp
